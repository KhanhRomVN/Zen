Up and running in four steps

1

Install

Open Extensions (Ctrl+Shift+X), search Zen and click Install.

2

Open Zen

Find it in the Activity Bar.

3

Connect

Enter an API key, or log in to an AI website and let Zen use that session.

4

Ask

Type “Fix the bug in handleSubmit” and watch it work.

Prefer the terminal? A command-line version, ZenCLI, is also available.

Private by design

Zen is a pure client. Requests go straight from your machine to the provider you choose.

  • All conversations and data stay on your machine
  • No intermediate Zen server, nothing collected
  • Public source on GitHub under MIT
  • Web-account sessions may be subject to each provider’s terms of service. Please review them.

Questions

Is Zen really free?

Yes. The extension is free and open source (MIT), and it can use free AI web accounts with high usage limits.

Where does my data go?

Nowhere but your machine and your chosen provider. Zen has no server and collects nothing.

Can the agent break my code?

Every edit gets an automatic checkpoint, with one-click diff and revert. You also pick how much autonomy it has.

Which AI providers work?

ChatGPT, Claude, Gemini, Qwen, GitHub Copilot, DeepSeek, Ollama and any OpenAI-compatible endpoint.
